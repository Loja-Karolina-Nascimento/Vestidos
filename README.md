# Karolina Nascimento — Protótipo de loja virtual

Site estático responsivo em HTML, CSS e JavaScript. Não requer instalação.

## Como visualizar
Abra `index.html` no navegador. Para publicar, envie os arquivos para a raiz do repositório e ative GitHub Pages em Settings > Pages > Deploy from a branch.

## Como personalizar
- `produtos.js`: nomes, fotos, preços, cores, tamanhos e descrições.
- `styles.css`: cores, fontes e layout.
- `index.html`: textos, contato e informações institucionais.
- `script.js`: catálogo, carrinho e simulação de checkout.

## Atenção: protótipo, não e-commerce operacional
- O checkout é **apenas uma simulação**: não registra pedidos, não cobra Pix, cartão ou boleto e não envia dados a servidores.
- O frete é um valor fictício, não uma cotação de transportadora.
- O parcelamento em 6x é ilustrativo, sem integração com adquirente ou taxas.
- Os produtos, estoques, cores, tamanhos e fotos são fictícios. Fotos carregam de URLs externas e devem ser substituídas por imagens autorizadas dos seus produtos.
- Para operar vendas reais, integre um gateway/checkout confiável (ex.: Mercado Pago, PagSeguro ou outra plataforma), gestão de estoque, frete e políticas de privacidade/trocas. Nunca colete dados de cartão diretamente em um site estático.
- Não foram inventados endereço completo, telefone ou chave Pix. Insira-os após confirmar os dados.
